# 初音ミク Facet

Edit and push; the 初音ミク Facet tab rebuilds from this file.

- Each `##` heading is one concert. Its photos go in `content/miku/<concert>/`,
  using the heading in lower case with dashes, e.g. `content/miku/magical-mirai-osaka-2014/`.
- Each concert shows two photos: the first two files in its folder, sorted by name
  (name them `1.jpg` and `2.jpg` to pick the order).
- Plain text under a heading is shown below the photos as that concert's description.
