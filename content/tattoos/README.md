# Tattoo Facet photos

Drop photos into the folder for each area and push:

- `left-forearm/`
- `right-forearm/`
- `wrists/`
- `chest/`

Each area shows a "Photo coming soon" box until its folder has a photo.
Formats: .jpg, .jpeg, .png, .webp, .avif (export iPhone .heic as JPG).
Multiple photos per area are fine; they show in filename order.

A new `##` area in `content/tattoos.md` gets its photos from a folder with
the same name in lower case with dashes (e.g. "Upper back" → `upper-back/`).
