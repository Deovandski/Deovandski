# Cat Dad Facet (Peeta photos)

Drop photos of Peeta straight into this folder and push. They appear in the
"Cat Dad Facet" tab on the home page.

- Formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif` (export iPhone `.heic` as JPG).
- Order: photos are shown in filename order. Number them to control it:
  `01-first-day-home.jpg`, `02-asleep-on-keyboard.jpg`, …
- Descriptions: the filename becomes the photo's caption on the grid
  (above the photo), in the zoomed view and for screen readers. `02-asleep-on-keyboard.jpg` shows as
  "Asleep on keyboard", so name files after what's in them.
- Full-size originals are fine; the site makes small, fast copies.
- `_intro.md` holds the text shown above the photos. Edit it freely.
