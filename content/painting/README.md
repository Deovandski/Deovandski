# Painting/Drawing pictures

Drop pictures here (.jpg, .jpeg, .png, .webp, .avif) and push; the Painting/Drawing tab rebuilds.

- Each picture is captioned with the date it was taken (MM/DD/YYYY): from the photo's own
  metadata (EXIF "date taken"), otherwise a date in the filename (`20240221_…`,
  `IMG_20240221_…`, `PXL_20230305_…`, or `2013-02-03` anywhere), otherwise `--/--/----`.
- Pictures are shown oldest first; undated ones go last, in filename order.
- Keep the original files: resizing or "export for web" can strip the date.
- To give an undated picture a date, rename it with one, e.g. `2013-02-03-IMG_1771.JPG`.
