# Fishing photos

Works exactly like the Cat Dad tab (`content/peeta/`). Drop fishing photos
straight into this folder and push; they appear in the Fishing tab.

- Formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif` (iPhone `.heic` saved as
  `.jpg` is converted automatically at build time).
- Order: photos are shown in filename order. Number them to control it:
  `01-first-walleye-lake-of-the-woods.jpg`, `02-ice-fishing-2023.jpg`, …
- Descriptions: the filename becomes the photo's caption on the grid
  (above the photo), in the zoomed view and for screen readers. `02-ice-fishing-2023.jpg` shows as
  "Ice fishing 2023", so name files after what's in them.
- Full-size originals are fine; the site makes small, fast copies.
- `_intro.md` holds the text shown above the photos. Edit it freely.
