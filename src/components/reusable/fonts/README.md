# DSEG7 Classic

`DSEG7Classic-Bold.woff2` is **DSEG7 Classic** by keshikan, copied unaltered from the
[dseg](https://github.com/keshikan/DSEG) package so `LedClock.astro` looks like an old red LED
display. License: SIL Open Font License 1.1, see [DSEG-LICENSE.txt](DSEG-LICENSE.txt). Copy this
folder along with `LedClock.astro` when you reuse the clock in another project.
